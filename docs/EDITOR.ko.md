# EZPZ File JTD 에디터 설계

목표: rhwp-studio처럼 **엔진이 직접 그리는 자체 에디터**. 화면과 조작은 一太郎 사용자가 바로 쓸 수 있게 맞춘다.
상표·로고·아이콘·고유 색은 쓰지 않는다. 배치와 조작 방식(어디에 무엇이 있고 어떤 키가 무엇을 하는지)만 맞춘다.

## 1. 구조

```
┌──────────── 브라우저 / 맥 앱(WebView) ────────────┐
│ UI (JavaScript, 빌드 도구 없음)                     │
│  메뉴바 · 툴바 · 점프팔레트 · 툴팔레트 · 눈금자      │
│  상태표시줄 · 시트탭 · 대화상자                      │
│  숨은 textarea ← 키 입력·IME(일본어 변환)            │
│  <canvas> 쪽마다 하나 ← 표시 목록을 그리기만 함       │
└───────────────▲───────────────┬───────────────────┘
                │ JSON(쪽별 표시 목록,│ 명령(글자 넣기, 굵게, …)
                │ 커서 위치, 서식 상태)│
┌───────────────┴───────────────▼───────────────────┐
│ ezjtd-core (Rust → WebAssembly)                    │
│  read  : jtd → 문서 모델                            │
│  edit  : 커서·선택·입력·삭제·서식·표·되돌리기        │
│  layout: 字×行 격자 배치, 금칙, 쪽 나눔, 표          │
│  export: docx · html · md · txt                    │
└────────────────────────────────────────────────────┘
```

- **문서 모델이 진짜 원본**이다. 화면은 모델을 그린 결과일 뿐이라 `contenteditable`의 불안정함이 없다.
- 레이아웃은 一太郎처럼 **문자 격자(字×行)** 기준. 기본 A4 · 40字 × 36行 · 10.5pt. 전각 1칸, 반각 0.5칸.
- 일본어 입력: 숨은 textarea가 변환 중인 글자(preedit)를 받으면 엔진이 커서 자리에 밑줄로 끼워 배치한다.
  변환 후보 창이 커서 옆에 뜨도록 textarea를 커서 위치로 옮긴다.
- 매 입력마다 전체 다시 배치(문서가 수십 KB라 1ms 안팎), JS는 **보이는 쪽만** 다시 그린다.
- 되돌리기: 편집 전 상태 스냅샷, 최대 100회(一太郎 기본값과 같음). 연속 입력은 한 번으로 묶는다.

## 4. 저장

- **v0.2**: Word(.docx) · HTML · 텍스트 · Markdown · PDF(인쇄). 원본 jtd 문서 정보(작성자·원래 경로)는 docx에 옮기지 않는다.
- **jtd로 저장은 아직 안 한다.** 一太郎가 확실히 여는 파일을 만들려면 LineMark·PageMark 등 위치 표 규칙을 먼저 풀어야 한다(기획서 5단계).
  메뉴에는 보이되 "준비 중"으로 비활성.

## 5. 아직 모르는 것 때문에 생기는 차이

- 용지·여백·字×行 설정을 아직 못 읽는다 → 모든 문서를 A4 40×36으로 배치. 원본과 줄바꿈 위치가 다를 수 있다.
- 가로 괘선 위치를 모른다 → 표의 가로선은 연한 선으로 표시.
- 글꼴 번호 해석 전 → 明朝 하나로 표시.

## 6. 현재 상태 (v0.2, 2026-10-01)

**된다**
- 새 문서 / jtd 열기(끌어놓기·Ctrl+O) / 시트 탭
- 입력: 일본어 IME(변환 중 글자를 밑줄로 표시), 붙여넣기, 덮어쓰기(Insert), Tab(표 안에서는 다음 칸)
- 커서: 화살표·Home/End·PageUp/Down·단어 이동, 마우스 클릭·드래그·더블클릭 선택, 표 안에서 위아래는 같은 열로
- 편집: 줄바꿈·삭제(문단 합치기), 선택 영역 바꾸기, 되돌리기/다시 하기(100회), 繰り返し(Ctrl+R)
- 서식: 太字·斜体·下線·문자 크기(목록 단계)·문자색, 왼쪽/가운데/오른쪽 정렬, 改ページ
- 罫線: 표 만들기, 행 위/아래 삽입·삭제
- 검색·치환(전체 치환 포함), 문자 수, 和暦 날짜 넣기
- 화면: 메뉴(Esc·Alt+문자·화살표 조작), 툴바, 점프팔레트(쪽 목록·문서 정보·원래 저장 경로 경고), 툴팔레트, 눈금자, 상태표시줄, 편집 기호, 배율(Ctrl+휠), 휴대폰 폭 맞춤
- 저장: Word(.docx)·HTML·텍스트·Markdown, 인쇄/PDF(쪽 그림으로 정확히 인쇄)
- 검증: 엔진 테스트 14개 + 공개 jtd 40개에 무작위 편집 4,000회 × 5회 돌려도 멈춤 없음. 브라우저 자동 테스트로 입력·IME·표·저장·메뉴 확인

**아직**

- 세로쓰기, 그림, 머리말·꼬리말, 들여쓰기·줄 간격 설정, 글꼴 선택
