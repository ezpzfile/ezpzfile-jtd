# 짝 샘플 만들기: 이치타로가 있을 때 할 일

[日本語](paired-samples.ja.md) · [English](paired-samples.en.md) · **한국어**

이치타로(체험판 포함)가 깔린 윈도 PC에서 아래 파일들을 만들면, 남은 규격을 빠르게 풀 수 있다.
방법은 간단하다: **새 문서에 글자를 넣고 저장 → 설정 하나만 바꿔서 다른 이름으로 저장.**
두 파일의 차이가 곧 그 설정이 저장되는 자리다.

파일 이름 규칙: `번호-무엇-값.jtd` (예: `03-margin-left-30mm.jtd`). 가능하면 같은 문서를 **PDF로도** 저장해 둔다.

| 번호 | 바꾸는 것 | 만들 파일 | 풀리는 것 |
|---|---|---|---|
| 01 | 기준 | `あいう` 한 줄만 쓴 문서 | 비교 기준 |
| 02 | 용지 | A4 세로 / A4 가로 / B5 | PaperMark·PageLayoutStyle |
| 03 | 여백 | 왼쪽 여백 20 / 30mm | 여백 단위 |
| 04 | 글자 수·줄 수 | 40자×36행 / 30자×30행 | 문자 격자(괘선 좌표 단위) |
| 05 | 들여쓰기 | 왼쪽 들여쓰기 2자 / 첫 줄 1자 | TLV 0x26 |
| 06 | 줄 간격 | 줄 간격 1.0 / 1.5 / 2.0 | TLV 0x20 |
| 07 | 글꼴 | MS明朝 / MSゴシック / 游明朝 | 서식 3·8번 |
| 08 | 글자 장식 | 기울임 / 취소선 / 위첨자 / 아래첨자 / 형광펜 | 서식 6~12, 16~20번 |
| 09 | 괘선 표 | 2×2 표 (실선) / 같은 표 (점선) / 같은 표 (굵은 선) | 가로 괘선 위치·선 종류 |
| 10 | 괘선 칸 합치기 | 3×3 표에서 가운데 칸 가로 합치기 | 합친 칸 표현 |
| 11 | 세로쓰기 | 같은 글을 세로쓰기로 | 세로쓰기 플래그 |
| 12 | 머리말·꼬리말 | 머리말 `ヘッダ` / 쪽 번호 | Header 조각 |
| 13 | 각주 | 각주 1개 | Footnote 조각 |
| 14 | 그림 | PNG 1장 넣기 | 그림 개체 |
| 15 | 압축 저장 | 같은 문서를 `.jttc`로 | LHA 압축 |
| 16 | 여러 시트 | 시트 2장 | DocItemInfo |
| 17 | 글자 수정 | 01번에서 `あいう` → `あいうえ` | **다시 저장할 때 바뀌는 숫자들** |

17번이 가장 중요하다. 글자 하나 늘렸을 때 같이 바뀌는 숫자(LineMark·PageMark·위치 표)를 알면
jtd로 다시 저장하는 일이 더 확실해진다.

만든 파일은 `corpus/local/paired/` 에 두면 된다(저장소에는 올라가지 않음).
